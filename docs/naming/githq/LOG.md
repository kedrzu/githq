# Naming log: githq

## Round 1 — 2026-10-30

**Owner's ask.** Research names with domains; tech TLDs preferred; strong preference for "git…" names;
current githq is liked; GitHive was on his mind.
**Directions.** git + place word, the HQ idea (31 checked); git + work/planning word (27); git + speed/calm
(15); everyday single words without git, the "command post" idea (30). Tech TLDs: dev, app, io, sh, so; .com too.
**What came out.**
- Every git+word .com is taken except odd ones (GitAttic, GitCourt, GitTriage, GitAgenda, GitRoster,
  GitBrisk, GitTidy, GitNeat, GitChores). .sh and .so are open for nearly everything, .io for about half,
  .dev/.app for maybe a third (many Google-registry lookups came back `unknown` from rate limiting).
- Everyday single words without git are taken on every TLD — that direction is closed for bare names.
- Big finding: the Git trademark policy forbids Git as a syllable/portmanteau in third-party marks. Applies
  to all Git* names equally; widely ignored, never seen enforced against small tools, but worth a decision.
- GitHQ: .dev ($12.87/yr), .app ($14.93/yr), .io ($51.80/yr) confirmed free at Porkbun; only conflicts are
  a dead 2011 PHP project (githq.org) and an unrelated Chinese company. Strongest candidate.
- GitHive: githive.dev and .app taken; a GitHub AI companion (Product Hunt 2025) and a git-over-DHT
  prototype use it. Dropped.
- GitCamp: active open-source git forge with issues at gitcamp.net. Dropped.
- Conflict search: Exa web search (GitHQ, GitHive, GitCamp/GitNest/GitKeys). No app stores, TMview or USPTO yet.
**Best.** GitHQ (.dev/.app/.io free). Runner-ups with .dev+.app open: GitNest, GitHarbor, GitTask, GitShed,
GitBarn, GitTeam, GitDaily, GitKeys, GitZoom (conflicts not yet checked beyond GitNest).
**Proposed next.** Owner decides on the trademark question. If he keeps githq: confirm on TMview/USPTO and
done. If he wants alternatives: conflict-check the runner-ups, and open a "<word> for GitHub"-free direction
of two-word compounds without git (e.g. verb+noun) as a hedge.
