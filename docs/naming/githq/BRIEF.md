# Naming: githq

**What it is.** A fast, keyboard-first web app that turns GitHub Issues, Pull Requests and Projects (v2)
into a Linear-grade task manager. A client for GitHub, not a new tracker; open source spirit, free.
**Space.** GitHub clients and dev task trackers: Linear, ZenHub, GitHub Projects, GitKraken, Plane, Height.
**Audience.** Individual developers and small teams who already work on GitHub, often OSS maintainers.
**Languages.** English name.
**TLDs.** Tech TLDs preferred (.dev, .app, .io, .sh, .so); .com nice but not required. Generic TLDs
acceptable if nothing technical is open (owner, round 1).
**Working name.** githq (git + HQ, "headquarters": one place to run your repos, projects and issues).

## Standing preferences
- Strongly prefers names starting with "git" — instantly says what the product is (round 1).
- Open to other names, but "git" names come first (round 1).
- Considered GitHive himself (round 1).
- Git trademark policy is not a concern — "we don't worry about licensing the Git name" (after round 1).

## Known constraints
- Git trademark policy (git-scm.com/about/trademark §2.3) forbids "Git" as a syllable or part of a
  portmanteau in a third-party mark; GitHub and GitLab are licensed exceptions. Many products ignore it
  (GitKraken, Gitpod, GitBook, GitButler, Gitea). The policy's sanctioned form is "<Name> for Git".
  Owner decided to ignore it (after round 1).
